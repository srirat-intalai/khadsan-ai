# ชุดรูปที่ทีมรวบรวมเพิ่ม (Team-collected set) : ข้อสอบรูปนอก dataset

รูปที่ได้มา 3,856 ไฟล์ ใช้เป็นข้อสอบอย่างเดียว ไม่ได้เทรน (รูปไม่มีกรอบ ใช้ชื่อโฟลเดอร์เป็นคำตอบ ดูกรอบที่ AI มั่นใจที่สุดในรูป)
ก่อนวัดผล ตัดออก : รูปสไตล์ Kaggle ชุดเดียวกับที่ใช้เทรน (Apple_Bad 914 รูป) / ส้มทำเทียมที่แปะบนรูปอื่น / รูปที่ Roboflow ทำซ้ำหลายเวอร์ชัน / รูปซ้ำกันเอง / รูปที่คล้ายรูปเทรนหรือข้อสอบเดิม
แยกเป็น 2 กลุ่ม

- **web (444 รูป)** : รูปที่หามาจากเว็บ ไม่ได้มาจาก Roboflow = ข้อสอบอิสระจริง
- **rf (315 รูป)** : รูปที่ export มาจาก Roboflow ไม่รู้ว่ามาจากชุดไหน อาจใกล้กับข้อมูลที่เคยใช้

## สรุป

- รูปจากเว็บจริง โมเดลยังทายถูกต่ำ (แบบ 11 = 42.8%) ต่างจาก test เดิม (F1 0.947) และ Kaggle (98.2%) มาก
  แปลว่าโมเดลเก่งกับรูปที่หน้าตาคล้ายชุดเทรน แต่ยังใช้กับรูปจริงทั่วไปได้ไม่ดี
- กล้วยกับส้มทำได้ดี (88–95%) จุดอ่อนหนักคือ **มะนาวเน่า** (ถูก 4/65 ส่วนใหญ่โดนทายเป็นส้ม เพราะมะนาวเน่าสีเหลือง-น้ำตาล) และ **ทับทิมเน่า** (ถูก 6/97 โดนทายเป็นส้ม แอปเปิล หรือหาไม่เจอ)
- แบบ 11 ดีกว่าแบบ 8 บนกลุ่ม web (+5.4 จุด, เน่าที่บอกว่าสดลดจาก 76 เหลือ 55) แต่แย่กว่าบนกลุ่ม rf (−6.3 จุด)
- งานต่อไปที่ช่วยได้จริง : เพิ่มรูปเทรนมะนาวเน่ากับทับทิมเน่าจากแหล่งที่หลากหลาย (มีกรอบ) แล้วเก็บรูปกลุ่ม web นี้ไว้เป็นข้อสอบ

ไฟล์ : `team_collected_web.csv`, `team_collected_rf.csv` (รายประเภททั้ง 2 โมเดล 2 ค่าความมั่นใจ)
