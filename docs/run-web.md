# วิธีรันเว็บ KhadSan AI (Mac / Windows)

ไฟล์นี้บอกตั้งแต่ลงโปรแกรม เปิดเว็บ ทดสอบ จนถึงเปิดให้คนอื่นใช้จากมือถือ
ถ้าจะเทรนโมเดลใหม่ ดู [train-model.md](train-model.md)


## 1. ของที่ต้องมีก่อน (ลงครั้งเดียว)

- **Python 3.12**
  - Mac : โหลดจาก https://www.python.org/downloads/ แล้วลงตามปกติ
  - Windows : โหลดจากที่เดียวกัน ตอนลงต้องติ๊ก **"Add python.exe to PATH"** ที่หน้าแรกด้วย ไม่งั้นพิมพ์ `python` แล้วจะไม่เจอ
  - เช็กว่าลงแล้ว : Mac พิมพ์ `python3 --version` / Windows พิมพ์ `python --version` ต้องขึ้น 3.12.x
- **Git** (ใช้โหลดโค้ดจาก GitHub)
  - Mac : พิมพ์ `git --version` ถ้ายังไม่มี เครื่องจะถามให้ลงเอง กดลงได้เลย
  - Windows : โหลดจาก https://git-scm.com/download/win ลงตามค่าเดิมทั้งหมด
- เน็ต (ตอนลงไลบรารีครั้งแรก ไฟล์ใหญ่ เพราะมี PyTorch มาด้วย)

ที่ต้องพิมพ์คำสั่ง : Mac ใช้แอป **Terminal** / Windows ใช้ **PowerShell** (กดปุ่ม Windows แล้วพิมพ์ PowerShell)


## 2. ลงครั้งแรก

**Mac**

```bash
git clone https://github.com/srirat-intalai/khadsan-ai.git
cd khadsan-ai/web
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

**Windows (PowerShell)**

```powershell
git clone https://github.com/srirat-intalai/khadsan-ai.git
cd khadsan-ai\web
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

อธิบายทีละบรรทัด
- `git clone` โหลดโค้ดทั้งหมดมาไว้ในโฟลเดอร์ `khadsan-ai` (ไฟล์โมเดล `web/models/best_detect.pt` มาด้วย ไม่ต้องหาเพิ่ม)
- `python -m venv venv` สร้างกล่องแยกไว้ลงไลบรารีของโปรเจกต์นี้ จะได้ไม่ปนกับโปรแกรมอื่นในเครื่อง
- `activate` เปิดใช้กล่องนั้น ถ้าเปิดสำเร็จ หน้าบรรทัดคำสั่งจะมีคำว่า `(venv)`
- `pip install` ลง Flask, ultralytics (YOLO), Pillow ตามรุ่นใน `requirements.txt` ครั้งแรกจะนานหลายนาที

Windows ถ้าบรรทัด `Activate.ps1` ขึ้นว่า running scripts is disabled ให้พิมพ์อันนี้ครั้งเดียว แล้วลอง activate ใหม่

```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```


## 3. เปิดเว็บ

**Mac**

```bash
cd khadsan-ai/web
source venv/bin/activate
python app.py
```

**Windows (PowerShell)**

```powershell
cd khadsan-ai\web
.\venv\Scripts\Activate.ps1
python app.py
```

รอจนขึ้นว่า `Running on http://127.0.0.1:7860` แล้วเปิด **http://localhost:7860** ในเบราว์เซอร์
(ตอนเปิดเว็บ โปรแกรมจะโหลดโมเดลก่อน เลยรอไม่กี่วินาที)

ปิดเว็บ : กด `Ctrl + C` ในหน้าต่างที่รันอยู่

ครั้งต่อไปไม่ต้องลงใหม่ ใช้แค่ 3 บรรทัดในข้อนี้


## 4. ทดสอบว่าเว็บใช้ได้

เปิดเว็บไว้ แล้วไล่ลองตามนี้ (ใช้รูปผลไม้ที่ถ่ายเอง หรือรูปใน `train/datasets/fruits_quality/test/images` ถ้าโหลด dataset ไว้แล้ว)

| ลองทำ | ที่ควรเห็น |
|---|---|
| เลือกรูปผลไม้ 1 ลูก แล้วกด "ตรวจเลย" | ขั้นตอน 1-2-3 ติ๊กทีละขั้น แล้วขึ้นป้ายตรวจ รูปมีกรอบ และรายการทีละลูก |
| รูปที่มีหลายลูก มีทั้งสดและเน่า | ตรา "คัดออก N ลูก" สีอิฐ เลขลูกเน่าขึ้นในแถว "คัดออก" ขั้นที่ 3 ขึ้น "ต้องคัดออก" |
| รูปที่ไม่มีผลไม้ (เช่นรูปโต๊ะ รูปคน) | ตรา "ไม่พบผลไม้" และมีคำแนะนำให้ถ่ายใหม่ |
| เปลี่ยนนามสกุลไฟล์ .txt เป็น .jpg แล้วส่ง | กล่องสีอิฐ "เปิดรูปนี้ไม่ได้ ..." ขั้นที่ 1 ขึ้นกากบาท |
| ไฟล์รูปใหญ่เกิน 10 MB | ขึ้นเตือนตั้งแต่ตอนเลือกรูป |
| กด "เปิดกล้อง" แล้ว "ถ่าย" แล้ว "ตรวจรูปนี้" | ได้ผลเหมือนอัปโหลด |
| กด "เปิดกล้อง" แล้ว "สแกนสด" เล็งผลไม้ | กรอบขึ้นบนภาพสด แถบด้านบนบอกจำนวน มีลูกเน่าแถบเป็นสีอิฐ |
| ลองบนมือถือ (ดูข้อ 5) | หน้าไม่ล้นจอ ปุ่มกดง่าย กล้องหลังเปิดได้ |

ครั้งแรกที่ได้ผล การติ๊กขั้นตอนจะเล่นช้าๆ ราว 5 วินาที (ตั้งใจไว้ตอนเดโม) ครั้งต่อไปจะเร็วขึ้นเอง
กด "ดูผลทันที" เพื่อข้ามได้

ถ้าแก้โค้ดแล้วอยากเช็กเร็วๆ ว่าไม่มีอะไรพิมพ์ผิด

```bash
python -m py_compile app.py
```

ไม่มีอะไรขึ้นแปลว่าผ่าน


## 5. เปิดให้คนอื่นใช้จากมือถือ (วันนำเสนอ)

ใช้ Cloudflare Tunnel ทำลิงก์ https ชั่วคราว ฟรี ไม่ต้องสมัคร (กล้องมือถือต้องใช้ https ถึงจะเปิดได้)

ลง cloudflared ครั้งเดียว
- Mac : `brew install cloudflared` (ถ้ายังไม่มี brew ลงจาก https://brew.sh ก่อน)
- Windows : `winget install --id Cloudflare.cloudflared` ลงเสร็จแล้วปิด PowerShell แล้วเปิดใหม่

เปิด 2 หน้าต่าง
- หน้าต่างที่ 1 : เปิดเว็บตามข้อ 3
- หน้าต่างที่ 2 : พิมพ์

```bash
cloudflared tunnel --url http://localhost:7860
```

รอสักพักจะขึ้นลิงก์ `https://xxxx.trycloudflare.com` เอาไปเปิดในมือถือ หรือทำเป็น QR code ให้คนดูสแกน

- ลิงก์ใช้ได้ตอนที่ 2 หน้าต่างยังเปิดอยู่เท่านั้น ปิดแล้วลิงก์ตาย เปิดใหม่ได้ลิงก์ใหม่
- ใครมีลิงก์ก็เข้าได้ ใช้เสร็จแล้วปิด
- เว็บตรวจทีละรูป หลายคนส่งพร้อมกัน คนหลังจะรอคิวแป๊บนึง
- ก่อนวันจริงลองเปิดจากมือถือที่ใช้เน็ตมือถือ (ไม่ต่อ Wi-Fi เดียวกับโน้ตบุ๊ก) ดูหนึ่งรอบ


## 6. เจอปัญหา

| อาการ | แก้ยังไง |
|---|---|
| `python3: command not found` / Windows ไม่รู้จัก `python` | ยังไม่ได้ลง Python หรือ Windows ลืมติ๊ก Add to PATH ให้ลงใหม่แล้วติ๊ก |
| `No module named 'flask'` หรือ `'ultralytics'` | ยังไม่ได้ activate venv (หน้าบรรทัดไม่มี `(venv)`) หรือยังไม่ได้ `pip install -r requirements.txt` |
| `Address already in use` | มีเว็บเปิดค้างอยู่ ปิดหน้าต่างเดิม หรือเปลี่ยน port : Mac `PORT=7861 python app.py` / Windows `$env:PORT=7861; python app.py` แล้วเปิด localhost:7861 แทน |
| เว็บขึ้น "ยังไม่มีไฟล์โมเดล" | ไม่มี `web/models/best_detect.pt` ให้ `git pull` ใหม่ หรือเอาไฟล์จาก Drive ที่เทรนไว้มาวาง |
| กดเปิดกล้องแล้วไม่ขึ้น | ต้องเปิดผ่าน localhost หรือลิงก์ https และกดอนุญาตกล้อง ถ้ายังไม่ได้ ปิดแอปอื่นที่ใช้กล้องอยู่ (Zoom, Line) |
| รูปแรกตรวจช้า | ปกติ รูปต่อไปจะเร็วขึ้น |
| ทายผิดบ่อย | ถ่ายใกล้ขึ้น แสงพอ ไม่ย้อนแสง เห็นทั้งลูก และใช้ 5 ชนิดที่รองรับ (แอปเปิล กล้วย ส้ม ทับทิม มะนาว) |


## 7. ค่าที่ปรับได้ใน `web/app.py`

อยู่ตอนบนของไฟล์ แก้แล้วปิดเว็บ เปิดใหม่

| ค่า | ตอนนี้ | ใช้ทำอะไร |
|---|---|---|
| `MAX_MB` | 10 | ขนาดไฟล์ใหญ่สุดที่รับ (MB) |
| `CONF_MIN` | 0.40 | ความมั่นใจต่ำกว่านี้ไม่นับว่าเจอผลไม้ |
| `LOW_CONF` | 60 | ต่ำกว่านี้ (%) ขึ้น "ตรวจซ้ำ" |
| `HIGH_CONF` | 85 | ลูกที่ว่าสดแต่ต่ำกว่านี้ (%) ขึ้น "ควรดูอีกที" |
| `MAX_FRUITS` | 30 | รายการทีละลูกโชว์ไม่เกินกี่ลูก |

เปลี่ยนโมเดล : เอา `best_detect.pt` กับ `class_info.json` ตัวใหม่ไปทับใน `web/models/` แล้วเปิดเว็บใหม่
