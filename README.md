# KhadSan AI : เว็บตรวจความสดผักผลไม้

เว็บต้นแบบ (Proof-of-Concept) ของโครงงาน **ระบบตรวจระดับความสดและคัดเกรดผักผลไม้อัตโนมัติด้วยดีปเลิร์นนิง**
(Automated Fruit and Vegetable Quality and Freshness Classifier) วิชา CS461 AI for Business Solutions

ใส่รูปผักผลไม้ 1 ชิ้น (อัปโหลดหรือถ่ายจากกล้อง) แล้วเว็บจะบอก

- **ชนิด** ของผักผลไม้
- **สถานะ** สด หรือ เน่า
- **% ความมั่นใจ** ของโมเดล พร้อมอันดับรองลงมาอีก 2 อันดับ
- ถ้าความมั่นใจต่ำกว่า 60% ป้ายจะปั๊มว่า **ตรวจซ้ำ** แทนสด/เน่า
- กด **สแกนชิ้นต่อไป** เพื่อล้างรูปเดิมแล้วใส่ชิ้นใหม่ได้เลย
- ถ้าโมเดลทายผิด ผู้ใช้กด **ผลนี้ผิด?** แล้วเลือกชนิดกับสภาพที่ถูกได้ ระบบจะเก็บรูปกับคำตอบไว้ให้ทีมตรวจแล้วเอาไปเทรนใหม่ (human-in-the-loop)

> ใช้เพื่อการศึกษา เป็นตัวช่วยคัดแยกเบื้องต้น ไม่ได้ใช้รับรองคุณภาพอาหาร

## โมเดลที่ใช้

- ไฟล์ `models/best_model.keras` เทรนโดยฟิว (โค้ดเทรนอยู่ที่ [fifacnw/project_cs461](https://github.com/fifacnw/project_cs461))
- สถาปัตยกรรม MobileNetV2 เริ่มจากน้ำหนัก ImageNet แล้ว fine-tune ด้วยข้อมูลของโปรเจกต์
- ข้อมูล: [Fruit and Vegetable Diseases Dataset (Kaggle)](https://www.kaggle.com/datasets/muhammad0subhan/fruit-and-vegetable-disease-healthy-vs-rotten)
- 28 คลาส = 14 ชนิด × (Healthy / Rotten) รายชื่ออยู่ใน `models/class_info.json`
- ชนิดที่รู้จัก: แอปเปิล กล้วย พริกหยวก แครอท แตงกวา องุ่น ฝรั่ง พุทรา มะม่วง ส้ม ทับทิม มันฝรั่ง สตรอว์เบอร์รี มะเขือเทศ
- รับรูปขนาดเท่าไหร่ก็ได้ ข้างในโมเดลย่อเป็น 160×160 และปรับค่าสีเอง เว็บเลยส่งค่าสีดิบ 0–255

## วิธีติดตั้ง

ต้องมี **Python 3.12** (ทดสอบกับ 3.12.1)

**Mac**

```bash
git clone https://github.com/srirat-intalai/khadsan-ai.git
cd khadsan-ai
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

**Windows (PowerShell)**

```powershell
git clone https://github.com/srirat-intalai/khadsan-ai.git
cd khadsan-ai
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

## วิธีเปิดเว็บ

```bash
streamlit run app.py
```

แล้วเปิด http://localhost:8501 ในเบราว์เซอร์

- พอเปิดหน้าเว็บ โมเดลจะโหลดรอไว้เบื้องหลังประมาณ 5 วินาที ถ้าอัปรูปเร็วกว่านั้นจะรอนานขึ้นนิดหน่อย รูปต่อๆ ไปเร็ว
- ใช้รูปผักผลไม้ **ชิ้นเดียว พื้นหลังเรียบ แสงพอ** และเป็นชนิดที่โมเดลรู้จัก ถ้าเป็นชนิดอื่นหรือมีหลายอย่างในรูป โมเดลอาจตอบผิดได้ทั้งที่ % ความมั่นใจสูง
- โหมดถ่ายรูป: บนมือถือ เบราว์เซอร์จะเปิดกล้องให้เฉพาะเว็บที่เป็น HTTPS หรือ localhost เท่านั้น

## ข้อมูลที่ผู้ใช้แจ้งว่าผิด (สำหรับทีม)

- เก็บไว้ในโฟลเดอร์ `feedback/` (รูป + `feedback.csv` มีคอลัมน์ time, image, predicted_class, predicted_conf, correct_class) โฟลเดอร์นี้ไม่ขึ้น GitHub
- ดาวน์โหลดได้จากส่วน "สำหรับทีมพัฒนา" ท้ายหน้าเว็บ ต้องใส่รหัสทีมก่อน
- ตั้งรหัสในไฟล์ `.streamlit/secrets.toml` (ไม่ขึ้น GitHub):

```toml
FEEDBACK_PASSWORD = "รหัสของทีม"
```

- บน Streamlit Cloud ใส่บรรทัดเดียวกันที่ Settings → Secrets ถ้าไม่ตั้งรหัส ส่วนดาวน์โหลดจะไม่แสดง
- บน Streamlit Cloud ไฟล์ใน `feedback/` จะหายเมื่อเว็บรีบูตหรือหลับ ควรดาวน์โหลดเก็บไว้เป็นระยะ

## โครงสร้างไฟล์

```
app.py                  หน้าเว็บหลัก (Streamlit) + โหลดโมเดลและทำนาย
utils.py                ฟังก์ชันจัดการรูป (หมุนรูปให้ตรง, ย่อรูป, เตรียมข้อมูลเข้าโมเดล)
style.css               หน้าตาเว็บ
.streamlit/config.toml  สีธีม ฟอนต์ และตั้งค่าเซิร์ฟเวอร์
models/                 best_model.keras + class_info.json
static/hero.jpg         รูปหัวเว็บ
requirements.txt        ไลบรารีที่ต้องติดตั้ง (ล็อกเวอร์ชันไว้)
```

## การป้องกันในเว็บ

- รับเฉพาะไฟล์ jpg / png จริง ขนาดไม่เกิน 10 MB
- กันรูปที่จำนวนพิกเซลเยอะผิดปกติ (เกิน 50 ล้านพิกเซล)
- รูป png พื้นหลังโปร่งใส จะถูกวางบนพื้นขาวก่อนส่งเข้าโมเดล
- ถ้าไฟล์เสียหรือโหลดโมเดลไม่ได้ เว็บจะแจ้งเป็นภาษาไทย ไม่ล่ม
- ไม่แสดงข้อความ error ดิบของระบบให้ผู้ใช้เห็น และไม่ได้รัน JavaScript เพิ่มเอง

## หมายเหตุเรื่องเวอร์ชัน

โมเดลเซฟมาจาก Keras 3.16 (รุ่นทดลอง) ส่วนเว็บใช้ Keras 3.15.1 เลยโหลดด้วย `compile=False`
(อ่านเฉพาะตัวโมเดลสำหรับทำนาย ไม่อ่านค่าที่ใช้ตอนเทรน) ผลทำนายใช้งานได้ปกติ
